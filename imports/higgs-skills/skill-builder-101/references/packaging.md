# 패키징 · 설치 · 배포

스킬을 다 만들었으면, 남이(또는 내가 다음에) 쓸 수 있게 묶어야 합니다.

## 1) `.skill` 파일로 묶기 (가장 쉬움)

`.skill` 파일은 사실 **스킬 폴더를 zip으로 압축한 것**입니다(확장자만 `.skill`). Cowork에서
이 파일을 보여주면 카드에 **Save skill** 버튼이 떠서, 누르면 내 프로필에 설치됩니다.

명령으로 직접 만들기(폴더 안에서):

```bash
cd my-skill
zip -r /tmp/my-skill.skill SKILL.md references -x ".*"
# 그다음 원하는 위치로 복사
cp /tmp/my-skill.skill ./my-skill.skill
```

> 팁: 일부 환경(마운트된 폴더)에서는 zip이 바로 못 쓰이는 경우가 있어, `/tmp`에서 만든 뒤
> 복사하면 안전합니다.

만들었으면 Cowork에서 그 `.skill` 파일을 사용자에게 보여주고(present) Save skill 안내.

## 2) 설치·관리

- **설치**: `.skill` 카드의 **Save skill** 버튼(조직이 스킬 생성을 허용한 경우 표시됨).
- **관리/삭제**: 앱 **설정 > Capabilities**에서. (스킬 파일을 직접 편집한다고 설치본이 바뀌진
  않습니다 — 반드시 설정에서 관리.)
- **확인**: 설치 후 관련 주제로 대화하면 Claude가 자동으로 스킬을 켭니다. 확실히 부르려면
  트리거 문구를 말하거나 `/스킬이름`으로 호출.

## 3) git으로 버전 관리·공유

스킬 폴더를 git 저장소에 올려두면 이력 관리와 팀 공유가 쉽습니다.

```bash
cd 스킬들이-있는-폴더
git init
git add .
git commit -m "Add my-skill"
# GitHub 등 원격이 있으면:
git remote add origin https://github.com/<계정>/<저장소>.git
git branch -M main
git push -u origin main
```

> 주의: 원격 `push`는 로그인/토큰 인증이 필요합니다. 인증 입력은 **본인이 직접** 하세요.
> (에이전트가 비밀번호·토큰을 대신 입력하지 않습니다.)

`.gitignore` 권장(잡파일 제외):

```
.DS_Store
*.zip
/tmp/
```

## 4) 플러그인·마켓플레이스로 배포 (팀·대규모 공유)

스킬 여러 개나 MCP까지 함께 배포하려면 **플러그인**으로 묶습니다(→ `mcp-integration.md`의
방법 C). 여러 플러그인을 모아 **마켓플레이스**로 공개할 수도 있습니다. 이 세션의
`create-cowork-plugin` 스킬이 플러그인 골격 생성을 도와줍니다.

## 배포 전 최종 체크리스트

- [ ] `name`(폴더명과 일치, 소문자-하이픈)과 `description`(트리거 구체적)이 제대로 있는가?
- [ ] 본문이 500줄 이하이고, 긴 내용은 `references/`로 뺐는가?
- [ ] 규칙마다 "왜"가 설명돼 있는가?
- [ ] MCP를 쓴다면, 없을 때의 안내와 안전 주의가 들어갔는가?
- [ ] 실제로 한두 번 테스트해 의도대로 켜지고 동작하는가?
- [ ] 민감정보(토큰·비밀번호·개인정보)가 파일에 안 들어갔는가?
