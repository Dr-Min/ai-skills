# adaptive-mastery-tutor

> 설명을 한 번 보여주는 데서 끝내지 않고, 학습자가 실제로 이해하고 응용할 때까지 진단·설명·확인·복습을 반복하는 적응형 튜터입니다.

[전체 스킬 목록](../../README.md) · [실행 지침](SKILL.md)

## 해결하는 문제

일반적인 AI 설명은 읽을 때는 이해한 것 같지만 직접 설명하거나 문제에 적용하면 막히기 쉽습니다. 이 스킬은 학습자의 답을 증거로 삼아 다음 진도를 결정합니다. 이미 아는 부분은 빠르게 통과하고, 잘못 이해한 부분은 정확히 분리해 다시 확인합니다.

## 이런 요청에 사용합니다

- “완전 초보인데 처음부터 가르쳐줘.”
- “문제를 내면서 내가 이해했는지 확인해줘.”
- “내 답에서 틀린 사고방식을 찾아줘.”
- “이론을 실제 업무나 프로젝트에 적용하는 데까지 배우고 싶어.”
- 이전에 진행하던 대화형 학습을 이어가고 싶을 때

한 번의 사실 답변, 짧은 요약, 번역, 단순 구현 요청에는 사용하지 않습니다.

## 핵심 기능

- 선수지식 사슬을 만들고 첫 미확인 지점에서 시작
- 한 번에 하나의 핵심 개념만 설명
- 결론뿐 아니라 이유, 원리, 경계조건, 전이 능력을 평가
- 부분 이해와 오개념을 구분해 필요한 부분만 교정
- 다른 예시와 형식으로 취약 개념을 다시 확인
- 학습자 수준과 실제 사용 목적에 맞춰 속도와 난이도 조절
- 누적 실전 과제로 학습 완료 여부 확인

## 학습 흐름

1. 주제, 현재 수준, 최종 목표, 실제 사용 장면을 확인합니다.
2. 필요한 선수지식 지도를 짧게 보여주고 시작점을 정합니다.
3. 한 개념을 설명한 뒤 1~3개의 확인 질문을 냅니다.
4. 학습자의 답을 평가하고 정확한 부분과 결함을 분리합니다.
5. 중요한 오개념이 없을 때만 다음 개념으로 이동합니다.
6. 취약 개념은 복습 큐에 넣고 다른 형태로 다시 검사합니다.
7. 마지막에는 새 상황에 적용하는 누적 과제로 전이를 확인합니다.

## 입력과 결과물

입력은 학습하고 싶은 주제, 현재 경험, 목표와 사용 장면입니다. 결과는 고정된 강의문이 아니라 다음을 포함하는 대화형 학습 과정입니다.

- 개인화된 학습 지도와 현재 위치
- 개념별 설명과 연습 문제
- 답변에 대한 항목별 진단과 재확인
- 숙달·부분 이해·취약 개념 상태
- 실전 적용 과제와 다음 학습 제안

## 빠른 시작

저장소 루트에서 설치합니다.

```bash
python install.py --no-law-mcp --skills adaptive-mastery-tutor
```

설치 후 예시:

```text
$adaptive-mastery-tutor SQL을 한 번도 안 써봤어. 실제 매출 데이터를 조회할 수 있을 때까지 가르쳐줘.
```

## 학습 상태 저장

기본적으로 현재 대화에서만 상태를 유지합니다. 사용자가 명시적으로 저장을 요청한 경우에만 `~/.codex/learning-progress/<topic>.md`를 만들며, 자동으로 개인정보나 학습 기록을 디스크에 남기지 않습니다.

## 한계와 안전 경계

- 정답 용어를 외웠다는 이유만으로 숙달을 선언하지 않습니다.
- 법률·의료·세무·금융처럼 고위험 주제는 교육과 개인화된 전문 조언을 구분합니다.
- 최신 정보가 필요한 과목은 권위 있는 현재 자료를 확인한 뒤 수업에 사용해야 합니다.
