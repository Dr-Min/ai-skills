# cinema-studio-pipeline

> Higgsfield Cinema Studio와 Seedance를 사용해 이야기·자산·쇼트·연기·대사·편집·사운드를 하나의 검증 가능한 AI 영화 제작 흐름으로 운영합니다.

[전체 스킬 목록](../../README.md) · [실행 지침](SKILL.md)

## 해결하는 문제

AI 영상은 좋은 프롬프트 한 번보다 단계 사이의 인수인계가 더 중요합니다. 장소가 틀렸는데 캐릭터를 계속 수정하거나, 기준 이미지가 깨졌는데 영상 프롬프트로 감추려 하면 비용만 늘어납니다. 이 스킬은 각 단계가 다음 단계에 넘길 수 있는 증거를 만들었는지 확인하고, 가장 먼저 깨진 지점으로 돌아갑니다.

## 이런 작업에 사용합니다

- 단일 시네마틱 쇼트 또는 여러 장면의 AI 단편영화 제작
- 장소, 캐릭터, 소품, 상태 변형과 재사용 가능한 `@Element` 구축
- Soul Cinema, AI Cast, Nano Banana Pro, Seedream, GPT Image 모델 선택
- Seedance 프롬프트 작성·수정과 실패 원인 진단
- 공간 연속성, 시선, 연기, 대사, 목소리 일관성 관리
- 장편·팀 제작용 씬 블록, 네이밍, 승인 게이트 운영
- 편집, 정리, 색보정, 사운드 후반작업

## 제작 파이프라인

1. **Think** — 원인, 목표, 대가, 장애물, 발견, 선택과 쇼트 목적을 잠급니다.
2. **Setup** — 프로젝트 폴더, 자산 레지스트리, 이름 규칙과 기준 파일을 만듭니다.
3. **Generation** — 장소를 먼저 만들고 캐릭터·상태·소품·목소리를 스트레스 테스트합니다.
4. **Seedance** — 한 번에 진단 가능한 쇼트 또는 통제된 시퀀스를 연출합니다.
5. **Review** — 실제 픽셀과 소리를 보고 가장 먼저 깨진 인수인계를 수정합니다.
6. **Post** — 생성 중부터 편집하고, 마지막에 클린업·색·사운드를 통합합니다.

## 핵심 운영 원칙

- 프롬프트와 모델명은 약속일 뿐이며 렌더된 결과가 증거입니다.
- 장소를 캐릭터보다 먼저 확정해 빛, 물리, 공간 기준을 만듭니다.
- `@loc_`, `@char_`, `@prop_` 이름 규칙과 실제 플랫폼 레지스트리를 일치시킵니다.
- 기준 원본은 불변으로 두고 수정 패치와 합성 계보를 기록합니다.
- 진단 반복에서는 한 번에 한 변수만 바꿉니다.
- 10~15번의 통제된 시도에도 실패하면 쇼트를 단순화합니다.
- 캐릭터 정체성, 상태, 지리, 목소리를 검증하기 전에 대량 생성하지 않습니다.

## 입력과 결과물

입력:

- 이야기 또는 정확한 쇼트 목표
- 캐릭터·장소·소품 참조와 원하는 화면비
- 사용 가능한 모델, 크레딧, 길이, 음향 조건
- 반드시 유지해야 할 연속성과 금지 요소

결과:

- 승인된 이야기·쇼트 브리프
- 버전이 있는 자산과 descriptor, 실제 `@` 태그
- 정확한 프롬프트 버전과 활성 참조 목록
- 렌더 결과, 실패 진단, 변경 로그와 판정
- 편집·색·사운드까지 확인한 시퀀스

## 설치와 시작

```bash
python install.py --no-law-mcp --skills cinema-studio-pipeline
```

예시 요청:

```text
$cinema-studio-pipeline 이 40초 무성 단편을 이야기 구조부터 잡고, 장소와 캐릭터를 고정한 뒤 쇼트별 Seedance 프롬프트까지 만들어줘.
```

## 한계와 비용 경계

- 생성 서비스 연결과 크레딧이 필요합니다.
- 모델이 지시를 이해했다는 응답은 성공 판정이 아닙니다.
- 병렬 모델 실험은 불확실성 감소나 승인 가치가 비용을 정당화할 때만 사용합니다.
- 최종 화면비의 크롭, 캐릭터 정체성, 접촉·출입·시선, 음성 일관성을 실제 결과에서 확인해야 합니다.
