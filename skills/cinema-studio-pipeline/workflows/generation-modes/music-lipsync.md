# Generation mode — MUSIC_LIPSYNC

Use only when music or vocal performance must be generated with the source clip.

- Lock the final audio file, hash, sample rate, lyrics/phonemes, speaker ownership, and
  rights before video generation.
- Divide long performances at natural breaths or phrases; retain editorial handles.
- State exactly whose mouth owns each audible line and which visible people stay silent.
- Preserve the fixed voice descriptor and character behavior; do not let performance
  reset at every cut.
- Use music waveform or reference audio only in a provider-supported way verified at
  generation time. Record the actual UI settings.
- Keep general dialogue/action clips free of unintended music. Re-add the approved
  master audio in post when the generation workflow requires a silent visual render.
