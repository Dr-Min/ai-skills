# Generation mode — REFERENCE_TEXT_NATIVE

Use for dialogue, continuity, and ordinary cinematic coverage where active references
carry identity/materials and text carries geometry, action, behavior, and timing.

- Start from asset records backed by current central approvals and a centrally approved
  shot card, not a finished still.
- Assign one role to every active reference and repeat its verbatim descriptor.
- Make frame one occupied when the shot requires immediate readable relationships.
- Use one location map across the scene; do not inherit a reference's source framing
  unless explicitly contracted.
- Default to one continuous take. Define every internal cut when cuts are required.
- Store the output as an immutable raw take and diagnose it before any edit.
