# Higgsfield image routing

Verify the active UI and `capabilities.yaml` before choosing a current model. Treat
the following as preferred roles, not permanent product guarantees.

## Default roles

- Character identity and manual sheets: current Soul character route.
- Automatic character sheet: Cinema Studio AI Cast when its generated layout is fit
  for the project.
- Cinematic location or scene still: current Soul Cinema route.
- General edit of an approved original: current Nano Banana Pro route first.
- Texture-only recovery of skin, cloth, and surfaces: current Seedream route.
- Small local detail, readable text, or controlled view change after the first route
  fails: current GPT Image route.

## Generation contract

Use one coherent scene paragraph in decision order: format, camera, subject/action,
environment, light/color, and finish. Keep platform parameters in the UI and record
them in the artifact/take record. Describe desired visible states before local failure
locks.

## Edit contract

Start every edit from the immutable approved original. Ask for one change, list what
must remain fixed, produce a new candidate, and composite only the approved region.
Never stack full-frame edited derivatives. A frame that needs a new composition is a
new generation or view contract, not a surgical edit.

Inspect identity, anatomy, contact, materials, light, edges, text, and intended crop.
The model route is not proof of quality.
