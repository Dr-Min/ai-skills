# 경비 인정 3조건

> 출처: 3교시 강의 원고 Slide 38. 셋 중 하나만 빠져도 부인될 수 있음.

## 3조건

### ① 사업 관련성

**판단 기준:**

- 사업 수행에 직접·간접적으로 필요한가?
- 사업과 무관한 개인 지출이 아닌가?

**🟢 명확히 사업 관련:**

- 사무실 임대료 / 사업용 인터넷 / 거래처 미팅 식대 (메모 있음)
- 업무용 노트북·모니터 / 사업 관련 강의·도서

**🟡 메모 필요 (관련성 모호):**

- 카페 (작업용? 개인?) → "○○ 작업 / 거래처 미팅" 메모로 보강
- 책 (사업 관련?) → "○○ 활용 도서" 메모로 보강
- 식대 → "○○ 거래처 미팅" 메모

**🔴 세무사 확인 (관련성 의심):**

- 골프장 / 유흥업소 → 접대비 처리 가능 여부 별도
- 가족 식사 / 개인 여행 / 명품
- 개인 핸드폰 (사업·개인 혼용 시 비율)

**근거:** 소득세법 제27조 제1항

---

### ② 증빙 존재

**3만원 초과 → 정식 증빙 셋 중 하나 ⭐ (가장 자주 외울 것)**

1. **세금계산서**
2. **카드 매출전표** (카드 결제 시 자동)
3. **현금영수증 "지출증빙용"** (※ 소득공제용 X)

**3만원 이하 → 간이영수증 OK**

- 손글씨 영수증
- 단순 영수증 (편의점·식당)

**증빙이 없는 경우:**

- 카드 명세서 단독은 약함 (세무사가 인정 안 할 수도)
- 카드 매출전표 (전자영수증) 함께 보관 권장
- 영수증 분실 시 거래처에 재발급 요청

**근거:** 부가가치세법 시행령 제74조 (정규증빙 수취 범위)

---

### ③ 금액 적정성

**판단 기준:**

- 사업 규모·매출 대비 합리적인가?
- 동종 업계 평균 대비 과도하지 않은가?

**🟢 적정:**

- 매출 1억 사업가의 월 임대료 50만 원
- 사업 관련 도서 월 5만 원

**🟡 주의 (과다 의심):**

- 매출 1억 사업가의 월 식대 100만 원 (개인 비중 의심)
- 매출 5천만 사업가의 노트북 500만 원 (1대만)

**🔴 부인 가능 (과다):**

- 매출 1억 사업가의 골프 회비 월 200만 원
- 매출 5천만 사업가의 명품 가방 (사업용 주장)

**판단 도구:** 동종 업계 평균은 세무사 또는 국세청 통계 참조

## 3조건 통합 점검 표

```
| 항목 | ① 사업관련성 | ② 증빙 | ③ 금액적정성 | 분류 |
|---|---|---|---|---|
| Notion 구독 22,000 | ✅ | ✅ 카드 | ✅ | 🟢 |
| 스타벅스 38,000 | 🟡 (메모 필요) | ✅ 카드 | ✅ | 🟡 |
| 골프장 280,000 | 🔴 (의심) | ✅ 카드 | 🟡 | 🔴 |
| 현금 식대 45,000 | ✅ | ❌ (영수증 없음) | ✅ | ❌ 보완 필요 |
| 간이영수증 5만원 | ✅ | 🔴 (3만 초과) | ✅ | ❌ 정식증빙 재요청 |
```

## 분류 결정 트리

```
지출 발생
  │
  ├─ 사업 관련성? (조건 ①)
  │   ├─ 명확 ✅ → 다음
  │   ├─ 모호 🟡 → 메모 1줄 보완 → 다음
  │   └─ 의심 🔴 → 세무사 확인
  │
  ├─ 증빙 존재? (조건 ②)
  │   ├─ 정식증빙 ✅ → 다음
  │   ├─ 간이영수증 (3만 이하) → ✅
  │   └─ 증빙 없음·간이(3만 초과) → ❌ 보완 필요
  │
  └─ 금액 적정? (조건 ③)
      ├─ 적정 ✅ → 🟢 적합
      ├─ 주의 🟡 → 메모로 정당화
      └─ 과다 🔴 → 세무사 확인 + 일부만 인정
```
