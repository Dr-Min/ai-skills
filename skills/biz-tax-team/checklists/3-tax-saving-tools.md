# 1인사업자 절세 3종 세트

> 출처: 3교시 강의 원고 Slide 39. 이 셋만 챙겨도 1년에 100~200만원 절세 가능.

## 3종 카탈로그

### ① 노란우산공제 ⭐ 가장 강력 (1석 3조)

**3가지 효과:**

1. **소득공제 연 600만원 한도** (소득에 따라 차등)
2. **폐업 시 퇴직금 효과** (5년 이상 가입)
3. **가입 즉시 압류 방지**

**가입 자격:**

- 사업자등록증 보유 (1인사업자·법인 모두)
- 소상공인기본법상 소상공인

**한도 (2026년 기준 — MCP로 재확인 필수):**

- 사업소득 4천만 이하: 연 500만원
- 사업소득 4천~1억: 연 300만원
- 사업소득 1억 초과: 연 200만원

**근거:** 조세특례제한법 제86조의3 (소기업·소상공인 공제부금에 대한 소득공제)

**예상 절세액 (사업소득 8,000만 가정):**

- 한도: 연 300만원 (구간별)
- 적용 한계세율: 24% + 지방세 = 26.4%
- **절세: 연 79만원**
- - 폐업급여 + 압류 방지 효과 추가

**가입 방법:**

- 농협·신한·KB·하나 등 시중 은행 (5분이면 가입)
- 자동이체 설정
- 사업자등록증 + 신분증 필요

---

### ② IRP / 연금저축 ⭐ 두 번째로 강력

**효과:** 세액공제 13.2~16.5% (소득에 따라)

**한도:**

- IRP + 연금저축 합산 **연 900만원**
- 연금저축 단독 **연 600만원**

**세액공제율 (2026년 — MCP로 재확인):**

- 종합소득 4,500만 이하: 16.5% (소득세 15% + 지방세 1.5%)
- 종합소득 4,500만 초과: 13.2% (소득세 12% + 지방세 1.2%)

**근거:** 조세특례제한법 제86조의4 (연금계좌 세액공제)

**예상 절세액:**

- 한도 900만 × 13.2% = **연 119만원** (고소득)
- 한도 900만 × 16.5% = **연 149만원** (저소득)

**주의:**

- 55세 이전 중도해지 시 기타소득세 16.5% 부과 (혜택 환수)
- 연금 수령 시 연금소득세 (3.3~5.5%, 세율 낮음)
- IRP는 노후 보장 + 절세 동시

**가입 방법:**

- 증권사 (미래에셋·한투·삼성 등)
- 자동이체 권장 (월 75만 = 연 900만)

---

### ③ 기부금공제

**효과:** 사업자는 **필요경비 산입** 또는 **세액공제** 선택 가능

**한도:**

- 지정기부금: 사업소득의 30%
- 법정기부금: 사업소득의 100%

**근거:** 소득세법 제34조 (기부금의 필요경비 산입)

**적용 단체:**

- 공익법인 (기부금 영수증 발급 가능 단체)
- 종교단체
- 동문회·자선단체 (지정 여부 확인)

**예상 절세 (기부 100만원 가정):**

- 한계세율 24% + 지방세 = 26.4%
- **절세: 연 26만원**

**증빙:**

- 기부금 영수증 필수
- 세무사에게 전달

## 3종 통합 진단 표

**예시 — 사업소득 8,000만 1인사업자:**

| 절세 도구      | 한도         | 현재 활용  | 갭     | 활용 시 절세        |
| -------------- | ------------ | ---------- | ------ | ------------------- |
| ① 노란우산     | 300만        | 0 (미가입) | 300만  | **+79만/년**        |
| ② IRP·연금저축 | 900만        | 300만      | 600만  | **+79만/년**        |
| ③ 기부         | 사업소득 30% | 0          | (자유) | 100만 기부 시 +26만 |
| **합계**       |              |            |        | **연 184만**        |

→ 3종 풀 활용 시 **연 184만원 절세 가능**.

## 가입 우선순위

### 1순위: 노란우산 ⭐

- 가장 큰 효과 (절세 + 폐업급여 + 압류방지 1석 3조)
- 가입 5분
- 자동이체 설정 후 잊고 살기

### 2순위: IRP·연금저축 한도 증액

- 기존 가입자라면 한도까지 자동이체 증액
- 미가입자는 증권사 신규 개설

### 3순위: 기부금

- 거래 관계·동문회·종교단체 등 자연스러운 단체
- 영수증 발급 가능 단체 확인 후

## ⚠️ 주의사항

1. **한도·세율은 매년 변경 가능** — `search_law` 또는 `get_law_text`로 본법+시행령 재확인
