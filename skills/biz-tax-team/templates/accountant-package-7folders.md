# 세무사 전달 패키지 — 7폴더 구조 (표준 템플릿)

> biz-tax-team "패키지" 모드의 표준 출력 형식.
> 세무사가 좋아하는 사장 = 폴더로 정리해서 메모 1줄 붙여서 보내는 사장.

---

## 📁 폴더 구조

```
~/세무사패키지/{YYYY-MM}/
├── 01_요약.md                    ← 사장님 → 세무사 1쪽 메모
├── 02_매출_정리.csv              ← 거래처별 매출 + 세금계산서 발행
├── 03_경비_적합.csv              ← 🟢 분류된 경비
├── 04_경비_메모필요.csv          ← 🟡 분류된 경비 + 메모
├── 05_accountant-questions-10.md        ← 결정 필요 사항
├── 06_원천세_지급내역.csv        ← 외주 3.3% / 강사료 8.8%
├── 07_증빙_사진/                 ← 영수증 이미지 (3만원 초과만)
└── 99_체크리스트.md              ← 세무사 전달 전 사장 자체 점검
```

### 02*매출*정리.csv

**컬럼:**

```csv
일자,거래처,상품/서비스,금액(VAT 별도),VAT,세금계산서_발행,결제수단,비고
2026-04-03,A사,컨설팅 1회차,1000000,100000,발행,계좌이체,
2026-04-15,B사,로고 디자인,500000,50000,미발행(소비자),카드,
...
```

**점검 포인트:**

- 세금계산서 미발행 건은 사유 명시 (소비자 / 면세사업자)
- 현금 매출은 현금영수증 발급 여부 확인
- 카드 매출은 자동으로 홈택스에 누적됨

### 04*경비*메모필요.csv (🟡)

**컬럼:**

```csv
일자,항목,카테고리,금액,증빙종류,메모(사장 작성)
2026-04-08,스타벅스,식대·미팅,38000,카드,A사 거래처 미팅 (홍길동)
2026-04-15,교보문고 도서,교육·도서,65000,카드,AI 기획용 도서 『프롬프트 엔지니어링』
2026-04-22,KTX,교통비,46500,카드,B사 미팅 출장 (대전)
...
```

**메모 작성 원칙:**

- 식대: "거래처명 + 담당자 + 목적"
- 도서: "사업 활용 분야 + 책 제목"
- 교통: "출장 목적 + 거래처"
- 강의: "사업 관련성 + 강의명"

### 07*증빙*사진/ (폴더)

**파일명 규칙:** `{YYYY-MM-DD}_{거래처}_{금액}.jpg`

**예시:**

```
2026-04-08_스타벅스_38000.jpg
2026-04-15_교보문고_65000.jpg
2026-04-22_KTX_46500.jpg
```

**기준:**

- 3만원 초과 건만 (3만 이하는 카드명세 자동 처리)
- 흐릿하면 재촬영
- 이메일 영수증은 PDF로 저장


```
    │
    ├─ 분류 모드 결과 자동 활용 (없으면 분류 모드 먼저)

    │
    ├─ 매출 데이터 추출 → 02_매출_정리.csv
    ├─ 원천세 거래 → 06_원천세_지급내역.csv
    │
    ├─ 01_요약.md 자동 작성 (monthly-summary-1page.md 템플릿 활용)
    │
    └─ 99_체크리스트.md 자동 생성
```

## 📤 세무사 전달 방식

### 옵션 1: 클라우드 폴더 공유 (권장)

- 구글 드라이브 / 드롭박스 / 원드라이브 폴더 공유
- 세무사에게 보기 권한
- 매월 갱신

### 옵션 2: 압축 파일 메일 발송

- 매월 말일 .zip 압축
- 세무사에게 메일로 전송
- 제목: `[{회사명}] 2026-04 세무 자료`

### 옵션 3: 카톡 메시지 (빠른 소통용)

- 01\_요약.md 내용을 본문에 복붙
- 첨부: 02·03·04 파일

## 💡 세무사가 좋아하는 추가 팁

1. **매월 같은 형식**: 4월·5월·6월 모두 동일 폴더 구조 → 세무사 시간 절약
2. **변경 사항 표시**: 지난달 대비 큰 변화는 01\_요약.md에 별도 표시
3. **결정 필요한 것만 🔴**: 세무사 우선순위 분배 도움
4. **분기 신고 전 1주일 여유**: 늦지 않게 보내기
