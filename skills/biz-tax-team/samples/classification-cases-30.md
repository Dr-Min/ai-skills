## 📊 패턴 학습 — 자주 만나는 분류 결정 트리

### 🟢 자동 적합 패턴

- 사업용 카드 결제 + 명확한 사업 카테고리 (임대·통신·SaaS·외주·광고)
- 세금계산서 발행 받음 (가장 강력한 증빙)
- 카드 결제 명세서가 자동 사업 비용 분류

### 🟡 메모로 보완 패턴

- 카페·식당 → "거래처명 + 담당자 + 목적"
- 도서 → "책 제목 + 사업 활용 분야"
- 강의 → "강의명 + 사업 관련성"
- 교통 → "출장 목적 + 거래처"
- 야간/주말 작업 식대 → "작업 시점 명시"

### 🔴 세무사 확인 패턴

- 골프·유흥업소 → 접대비 한도·요건 별도
- 명품·고가품 → 사업용 입증 어려움
- 가족 동반 출장 → 개인 여행 의심
- 친지·지인 거래 → 객관적 거래 입증 필요

### ❌ 증빙 부족 패턴

- 현금 거래 + 영수증 없음 → 거래처에 재요청
- 간이영수증 (3만 초과) → 정식 증빙 재요청
- 해외 결제 → 카드 명세 + 사용 화면 캡처
- 송금 후 영수증 미수령 → 거래처 추적

## 💡 분류 정확도 향상 팁

### 1. 카드 명세서 카테고리 활용

- 신한·KB·삼성 등 카드사 앱에서 자동 분류 카테고리 활용
- "사업비" 카테고리로 미리 설정 (가능한 경우)

### 2. 메모는 결제 직후 즉시

- 1주일 지나면 무슨 미팅인지 기억 안 남
- 카카오톡 자기 자신에게 메시지 (시간·장소 자동 기록)

### 3. 모호한 건 🟡로 (🟢로 미루지 말 것)

- 메모 추가 시간 = 5분
- 세무사 부인 위험 회피 효과 ↑

### 4. 접대비는 별도 관리

- 한도 (소득세법 제35조) 있음
- 매월 접대비 합계 추적
