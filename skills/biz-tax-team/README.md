> 1인사업자·소상공인이 신고 직전 폭발하지 않게, 매월 30분으로 분산해 끝내는 1인 세무팀.

## 🚀 빠른 시작

### 슬래시 호출

```
/biz-tax-team 분류 ~/Desktop/2026-04_지출.csv
/biz-tax-team 패키지 2026-04
/biz-tax-team 절세
/biz-tax-team 시뮬 매출=1억 경비=4000만
/biz-tax-team 원천세 100만원 외주
/biz-tax-team 부가세 매출=8000만 매입=3000만 업종=온라인쇼핑몰
/biz-tax-team 상담준비 [고민]
```

### 자동 트리거 (자연어)

- "이번 달 영수증 분류해줘" → 분류 모드
- "노란우산 가입하면 얼마 절세?" → 절세 모드
- "외주비 100만원 줄 때 얼마 차감?" → 원천세 모드
- "5월 종소세 시뮬해줘" → 시뮬 모드

## 🔗 Korean Law MCP 연동

본 스킬은 `korean-law` MCP로 세법 본법 + 시행령 + 조회일자 실시간 인용:

| 모드   | 인용 법령                                             |
| ------ | ----------------------------------------------------- |
| 분류   | 소득세법 제27조, 시행령 제55조                        |
| 패키지 | 부가세법 시행령 제74조 (3만원 기준)                   |
| 절세   | 조세특례제한법 제86조의3·4, 소득세법 제34조           |
| 시뮬   | 소득세법 제55조 (8구간 누진세율), 지방세법 제103조의3 |
| 원천세 | 소득세법 제127조, 시행령 제184조                      |
| 부가세 | 부가세법 제61·62조, 시행령 제109조                    |

> ⚠️ memory `feedback_factcheck_source_mandatory.md` 정책 — 모든 세법 수치는 MCP 직접 조회 + 조회일자 명시.

## 🛡️ 안전 가드레일

1. **면책 고지 자동 출력** — 모든 답변 시작에 💰
2. **단정 표현 자동 감지** — "~합니다" → "~할 수 있습니다 / 세무사 확인"
3. **세법 수치 MCP 강제** — 기억 답변 금지
4. **본법 + 시행령 + 조회일자** — 모든 인용 필수
5. **신고서 작성·전송 금지** — 세무사 영역
6. **사업용 카드 분리 강하게 권고** — 답변 푸터에 1회씩

## 🆘 트러블슈팅

### 슬래시 호출 시 다른 스킬이 떠요

- SKILL.md 프론트매터 `user_invocable: true` 확인
- Claude Desktop 재시작

### 답변에 면책 고지 💰가 안 나와요

- SKILL.md "필수 면책 고지" 섹션 확인
- AI에게 명시: "답변 시작에 💰 면책 고지 추가해 주세요"

### 세율·한도 답변에 조회일자가 없어요

- Codex에서 `korean-law` MCP 도구가 활성화되어 있는지 확인
- AI에게 명시: "본법 + 시행령 조회 후 조회일자와 함께 인용"

### 분류 결과가 일반론이에요

- AI에게 명시: "내 업종(○○)에 맞춰 케이스별 메모 권고"
- `samples/classification-cases-30.md` 참조 명령
