# /biz-profile — 모든 스킬의 시작점 📋

10항목 인터뷰 + 사각지대 질문 10개 → JSON 저장 → 다른 모든 사업가-\* 스킬이 자동 로드.

> 4교시 워크북 1쪽을 그대로 디지털로.
> "30%만 채우셔도 됩니다. 나머지는 AI가 질문하면서 채워줄 거예요."

---

## ⚠️ 면책 고지

> 📋 본 프로필은 다른 사업가-\* 스킬의 답변 맥락 자료입니다. 개인정보 입력 주의.

---

## 사용 시점

### ✅ 호출해야 하는 경우

- **처음** 사업가-\* 스킬 사용 전 (프로필 없으면 다른 스킬이 자동 호출)
- 사업 정보가 **변경**됐을 때 (업종 전환·매출 구간 변화·과세 유형 변경)
- 4교시 워크북 1쪽 작성을 디지털로
- 키워드: `사업가사업프로필`, `사업 프로필`, `프로필`, `내 사업 정보`, `인터뷰`, `회사 소개`

### ⚠️ 호출하지 말아야 하는 경우

- 이미 프로필 있고 변경 사항 없을 때 (그냥 다른 팀장 스킬 호출)
- 법인 자본구조 입력 → `/startup-captable-kr` 사용

## 모드별 처리 흐름

### 1. 생성 모드 — 10항목 인터뷰

**인터뷰 흐름 (한 번에 하나씩):**

`templates/10-item-interview.md` 참조. 워크북 1쪽 정확 재현:

```yaml
1. 회사명:
2. 업종:
3. 사업자 형태: 개인사업자 / 법인 / 프리랜서 / 미등록
4. 과세 유형: 일반과세 / 간이과세 / 면세 / 모름
5. 고객 유형: B2B / B2C / B2G / 혼합
6. 매출 방식:
7. 자주 하는 거래:
8. 세무사 이용 여부: 있음 / 없음 / 분기별만 / 신고철에만
9. 사업용 카드·계좌 분리 여부: 분리 / 미분리 / 부분 분리
10. 가장 걱정되는 문제 1줄:
```

**처리:**

1. 1~10 순차 인터뷰 (한 번에 한 질문)
2. JSON 직렬화 → `~/.lbiz-aibu/profile.json` 저장
3. 자동으로 **추가 질문 10개** 생성 (다음 단계)

**모름·추후 확인 허용:** "30%만 채워도 됨" 원칙. 답을 강요하지 않음.

---

### 1단계 후속: 사각지대 추가 질문 10개

10항목 입력 후 자동 실행:

```
명령:
"위 사업 프로필을 읽고, 법무·세무·재무 관점에서
추가로 알아야 할 질문을 10개만 만들어 주세요. 사각지대 위주로요."
```

`templates/blindspot-questions-10.md` 형식으로 출력:

- 🟦 법무 사각지대 (3개)
- 🟩 세무 사각지대 (4개)
- 🟨 재무 사각지대 (3개)

**"추후 확인" 표시 허용:** 사장님이 7일 안에 채워야 할 진짜 숙제.

---

### 2. 갱신 모드

```
/biz-profile 갱신 매출방식
→ 7번 항목만 다시 인터뷰 → JSON 부분 업데이트
```

---

### 3. 확인 모드

```markdown
# 현재 사업 프로필

{10항목 표 출력}

## 누락 항목

- 4번 (과세 유형) — "모름" 상태 → 홈택스 확인 권장

## 마지막 갱신

- 2026-04-12 (3주 전) — 갱신 권장
```

## 주의사항

1. **한 번에 한 질문만** — 10개를 한 번에 던지지 않기
2. **답 강요 금지** — "추후 확인" 허용
3. **답변 평가·비판 X** — 격려 위주
4. **개인정보 주의** — 사업자번호·연락처는 마스킹 권장

### 톤

- 카페에서 풀어주는 느낌 (강의 톤)
- 격식 있지만 가볍게
- 격려 멘트 1~2회 ("좋아요, 이거 하나만으로도 30점이에요")
