# biz-profile 📋

[전체 스킬 목록](../../README.md) · [실행 지침](SKILL.md)

> 모든 사업가-\* 스킬의 공통 입력. 10항목 인터뷰 + 사각지대 질문 10개 → JSON 저장.

## 🚀 빠른 시작

```
/biz-profile 생성    # 10항목 인터뷰 시작
/biz-profile 갱신 매출방식  # 특정 항목만 업데이트
/biz-profile 확인    # 현재 프로필 표시
```

## 🧩 3개 모드

| 모드 | 트리거        | 산출물                        |
| ---- | ------------- | ----------------------------- |
| 생성 | `생성`        | 10항목 + 사각지대 10개 → JSON |
| 갱신 | `갱신 [항목]` | 부분 업데이트                 |
| 확인 | `확인`        | 현재 프로필 + 누락 항목       |

## 💾 저장 위치

`~/.lbiz-aibu/profile.json` — 모든 사업가-\* 스킬이 자동 로드.

## 🎯 핵심 원칙

- **한 번에 한 질문만** — 10개를 한꺼번에 X
- **30%만 채워도 OK** — 모름은 "추후 확인"
- **추후 확인 = 7일 숙제** — 모르는 걸 모르는 게 더 큰 문제

🛡️ 본 프로필은 다른 스킬의 맥락 자료입니다. 정확할수록 답변 품질 ↑.

## 수집하는 정보

사업 형태, 업종, 주요 상품·서비스, 고객과 매출 구조, 인력, 계약, 세무, 자금과 현재 가장 큰 고민을 질문합니다. 답변에서 드러난 법무·세무·재무 사각지대는 추가 질문으로 분리합니다.

## 결과물과 재사용

- 사람이 읽는 현재 사업 프로필
- 빠진 항목과 “추후 확인” 목록
- 다른 사업 스킬이 읽는 표준 JSON
- 변경된 항목과 마지막 갱신일

## 설치

```bash
python install.py --no-law-mcp --skills biz-profile
```

## 개인정보 경계

프로필은 사용자 로컬에만 저장하고 저장소에 커밋하지 않습니다. 주민등록번호, 계좌 비밀번호, 인증서, API 키처럼 다른 스킬 실행에 불필요한 비밀정보는 수집하지 않습니다.
