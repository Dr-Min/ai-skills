## 10개 질문 (순차)

### Q1. 회사명

"먼저 회사명을 알려주세요."

- 예시: "엘비즈파트너스"
- 1인 프리랜서면 본인 이름·예명 OK

### Q2. 업종

"무슨 사업을 하시나요?"

- 예시: "경영컨설팅 / 1인 디자인 / 온라인쇼핑몰 / 강의 / 외주 개발"
- 한국표준산업분류 코드 모르셔도 OK

### Q3. 사업자 형태

"사업자 형태는?"

- [ ] 개인사업자
- [ ] 법인 (1인 법인 포함)
- [ ] 프리랜서 (사업자 미등록)
- [ ] 미등록 / 준비 중

### Q4. 과세 유형

"과세 유형은?"

- [ ] 일반과세
- [ ] 간이과세
- [ ] 면세
- [ ] 모름

> 💡 모르시면 홈택스 → 사업자등록증명에서 확인.

### Q5. 고객 유형

"주 고객은?"

- [ ] B2B (기업 대상)
- [ ] B2C (개인 소비자 대상)
- [ ] B2G (정부·공공기관)
- [ ] 혼합

### Q6. 매출 방식

"어떻게 돈 버시나요?"

- 예시: "월 정기 구독 / 프로젝트 단위 / 시간 단위 / 상품 판매 / 광고 / 수수료"

### Q7. 자주 하는 거래

"자주 하는 거래는?"

- 예시: "1,000만원 미만 6개월 컨설팅 / 100만원 단발 외주 / 1만원 단가 상품 100개 판매"

### Q8. 세무사 이용 여부

"세무사 이용하시나요?"

- [ ] 있음 (월 고문)
- [ ] 분기별만
- [ ] 신고철(5월·1월)에만
- [ ] 없음

### Q9. 사업용 카드·계좌 분리 여부 ⭐

"사업용 카드·계좌가 개인과 분리되어 있나요?"

- [ ] 완전 분리
- [ ] 부분 분리 (카드만 OR 계좌만)
- [ ] 미분리 (개인용과 혼용)

> ⚠️ 미분리시 즉시 분리 권장 (강의 핵심 메시지)

### Q10. 가장 걱정되는 문제 1줄

"마지막으로, 사업하면서 가장 걱정되는 문제 한 줄로 말씀해 주세요."

- 예시:
  - "외상매출 회수 안 됨"
  - "4대보험 체납 누적"
  - "정책자금 진입 어려움"
  - "외주 비용 통제"
  - "매출 정체"
