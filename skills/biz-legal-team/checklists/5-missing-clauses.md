# 1인사업자 5빠진 조항 — 자주 누락되는 조항 카탈로그

> 출처: 3교시 강의 원고 Slide 20. 이 5개가 안 들어 있으면 사고 확률이 급상승.

## 카탈로그

### 1. 수정 횟수 제한 ⚠️ 가장 자주 누락

**왜 중요한가:** 1인 디자이너가 300만원 외주에서 20회 무한 수정 끝에 70%만 받고 끝난 사례 빈번.

**필수 명시 사항:**

- 허용 수정 횟수 (보통 2~3회)
- 1회당 추가 단가 (예: 50만원/회)
- 수정 요청 기한 (검수 후 N일 내)

**예시 조문:**

> "갑의 수정 요청은 회당 1주일 이내, 총 3회 이내로 한다.
> 3회 초과분은 1회당 50만원의 추가 비용이 발생한다."

### 2. 선급금 비율 ⚠️ 미수금 방지 핵심

**왜 중요한가:** 후불 100% 계약은 거래 상대 사정으로 한순간에 매출 0.

**필수 명시 사항:**

- 선급금 비율 (30% 이상 권장)
- 단계 지급 (50-30-20 또는 30-40-30)
- 잔금 지급 트리거 명시

**근거:** 민법 제565조(해약금)

### 3. 검수 기간 ⚠️ "검수 안 한 척" 방지

**왜 중요한가:** 검수 무한 지연 시 잔금 지급 미루는 거래 상대 빈번.

**필수 명시 사항:**

- 납품 후 검수 마감일 (예: 7일)
- 미통보 시 자동 검수 간주 조항
- 검수 거절 시 사유 서면화 의무

**예시 조문:**

> "을의 납품일로부터 7일 이내 갑의 서면 검수 결과 미통보 시
> 검수 통과로 간주하고 잔금 지급일이 시작된다."

### 4. 자료 제공 책임

**왜 중요한가:** 갑의 자료 미제공으로 일정 지연 → 책임 소재 불명확.

**필수 명시 사항:**

- 갑의 자료 제공 의무 + 마감일
- 자료 미제공 시 일정 자동 연장
- 추가 비용 발생 시 처리

**예시 조문:**

> "갑은 계약일로부터 7일 이내 다음 자료를 을에게 제공한다: \_\_\_\_.
> 미제공 시 납기는 제공일로부터 자동 연장된다."

### 5. 비밀유지 (NDA)

**왜 중요한가:** 사업 정보 유출 시 손해 발생, 책임 소재 불명확.

**필수 명시 사항:**

- 양방 의무인지 명시 (갑만 의무 — 독소 #9)
- 유효 기간 (계약 종료 후 2년 권장)
- 위반 시 손해배상 조항
- 예외 사항 (공지된 정보 등)

**근거:** 부정경쟁방지법 제2조

## 점검 시 사용 표 형식

```
| # | 조항 | 검출 | 권고 |
|---|---|---|---|
| 1 | 수정 횟수 제한 | ❌ | "수정은 N회까지, 추가는 1회당 ○만원" |
| 2 | 선급금 비율 | ✅ (30%) | OK |
| 3 | 검수 기간 | ❌ | "납품 후 7일 이내 검수, 미통보 시 자동 검수" |
| 4 | 자료 제공 책임 | ❌ | "갑의 자료 마감일 + 미제공 시 자동 연장" |
| 5 | 비밀유지 | ❌ | "양방 비밀유지 + 종료 후 2년" |
```

## 발견 시 권고

- 5개 모두 ✅ → "1인사업자 안전 장치 완비."
- 1~2개 누락 → "보완 협상 권고."
- 3개 이상 누락 → "🔴 추가 협상 필수, 변호사 검토 권고."
