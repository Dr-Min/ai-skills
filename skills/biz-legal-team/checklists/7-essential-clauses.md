# 7대 필수 조항 — 점검 카탈로그

> 출처: 3교시 강의 원고 Slide 19. 이 7개만 표시되어 있으면 위험도 80% 감소.

## 카탈로그

### 1. 업무 범위

**점검 포인트:**

- 구체적으로 명시되어 있는가? ("기타 부수업무" 같은 모호 표현 X)
- 산출물 형태(PDF, 코드, 디자인 시안 N개)까지 명시되었나?
- 추가 업무 발생 시 처리 방법(별도 견적/추가 비용)?

**근거:** 민법 제664조(도급 정의)

### 2. 기간

**점검 포인트:**

- 시작일·종료일 명시?
- 중간 마일스톤(검수 시점) 있나?
- 연장 요청 시 처리 방법?
- 자동 갱신 조건 — 일방 갱신은 위험 (독소 #6 참조)

**근거:** 민법 제152조(기간의 기산)

### 3. 대금

**점검 포인트:**

- 총액 명시?
- 지급 일정(일시불 / 단계 / 월정액)?
- **선급금 비율** — 30% 이상 권장 (미수금 5장치 ① 참조)
- VAT 포함/별도 명시?
- 지급 지연 시 이자율 명시?

**근거:** 민법 제655조(고용 계약), 상법 제54조(상사법정이율)

### 4. 수정 변경

**점검 포인트:**

- **수정 횟수 제한** 명시? (1인사업자 5빠진 조항 ①)
- 추가 수정 시 단가?
- 수정 요청 기한(검수 후 N일 내)?
- 무한 수정 권한 — 독소 #2 참조

### 5. 저작권

**점검 포인트:**

- 귀속 명확? (갑/을/공동)
- 양도 시 추가 보상 조항?
- 일방 양도 + 추가 보상 없음 — 독소 #5 참조
- 2차 활용 권한 분리?

**근거:** 저작권법 제45조(저작재산권의 양도)

### 6. 해지

**점검 포인트:**

- 양방 균형 해지권? (갑만 해지 가능 — 독소 #1)
- 사전 통지 기간(30일/60일)?
- 정당한 사유 정의?
- 위약금 또는 일할 정산?

**근거:** 민법 제544조~제546조(채무불이행과 해제), 약관규제법 제9조

### 7. 분쟁 해결

**점검 포인트:**

- 협의 → 조정 → 소송 단계 명시?
- 관할 법원 — 상대방 본사? (독소 #7 위험)
- 중재 vs 소송?
- 준거법 (한국법) 명시?

**근거:** 민사소송법 제8조(합의관할), 중재법

```
| ... |
```

## 발견 시 권고 톤

- 7개 모두 ✅ + 명확 → "기본은 갖춰진 계약입니다. 5빠진 조항(`5-missing-clauses.md`) 점검 권장."
- 1~2개 누락 → "🟡 주의 — 누락 조항 보완 협상 권고."
- 3개 이상 누락 → "🔴 위험 — 변호사 검토 필수."
