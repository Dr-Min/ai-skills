# biz-finance-team 🏦

[전체 스킬 목록](../../README.md) · [실행 지침](SKILL.md)

> 1인사업자·소상공인이 빈손으로 은행 안 가게 하는 1인 재무팀.
> 5개 모드: 자가진단·사업계획·5숫자·매칭·상담준비.

> "정책자금은 공짜 돈이 아니라, 내 사업을 설명하는 능력의 게임이다."

설치: `python install.py --no-law-mcp --skills biz-finance-team`

## 🚀 빠른 시작

### 슬래시 호출

```
/biz-finance-team 자가진단
/biz-finance-team 사업계획
/biz-finance-team 5숫자 매출=1470 고정비=320 변동비=480 잔고=850
/biz-finance-team 매칭 업종=온라인쇼핑몰 매출=8000만 목적=운전자금
/biz-finance-team 상담준비
[고민] 운전자금 1,000만 신청, 체납 4대보험 있음
```

### 자동 트리거 (자연어)

- "정책자금 받을 수 있나?" → 자가진단 모드
- "사업계획서 초안 좀" → 사업계획 모드
- "이번 달 매출/이익/잔고 정리" → 5숫자 모드
- "흑자도산 위험?" → 5숫자 모드 (위기 경보)

## 🛡️ 안전 가드레일

1. **면책 고지 자동 출력** — 모든 답변 시작에 🏦
2. **단정 표현 자동 감지** — "~합니다" → "~할 수 있습니다 / 공식 사이트 확인"
3. **🚫 "현재 모집 중" 단정 절대 금지** ⭐ — "공식 사이트 확인 필요" 라벨
4. **신용등급 추정·확정 금지** — 본인이 NICE/KCB 직접 조회
5. **사업계획서 100% 완성 금지** — "사장님 본인 수정 30%+ 필수"
6. **AI 빈출 표현 회피** — 혁신적인·패러다임·시너지·선도적인·맞춤형 솔루션

## 🆘 트러블슈팅

### 슬래시 호출 시 다른 스킬이 떠요

- SKILL.md 프론트매터 `user_invocable: true` 확인

### "현재 모집 중" 단정 답변이 나와요

- AI에게 명시: "모든 정책자금 항목을 '공식 사이트 확인 필요 — {URL}' 형태로 다시 작성"

### 사업계획서 초안에 AI 흔적이 많아요

- AI에게 명시: "혁신적인 / 패러다임 / 시너지 / 선도적인 / 맞춤형 솔루션 표현 모두 교체"
