# 매월 봐야 할 5숫자 카탈로그

> 출처: 3교시 강의 원고 Slide 54. 어려운 회계 용어 다 잊어도 됨. 이 5숫자만 매월.

## 5숫자

### ① 이번 달 매출

**정의:** 이번 달 모든 매출 합계 (카드 + 현금 + 세금계산서)

**점검:**

- 전월 대비 증가/감소 추세
- 거래처 집중도 (한 거래처 80%+면 위험)
- 외상매출 비중

**경보:**

- 전월 대비 30%+ 감소 → 🟡 주의
- 3개월 연속 감소 → 🔴 위기

---

### ② 이번 달 고정비

**정의:** 매출과 무관하게 매월 같은 금액 나가는 비용

**예시:**

- 임대료 (사무실·사업장)
- 통신비 (사업용 회선)
- SaaS 구독료 (Notion·Claude·Adobe·Slack 등)
- 직원 급여 (있다면)
- 보험료
- 노란우산·IRP 자동 납입

**점검:**

- 매출의 30~50% 권장 (1인사업자 기준)
- 60% 초과 → 🟡 주의 (변동성에 취약)
- 80% 초과 → 🔴 위기 (한 달 매출 부진하면 적자)

---

### ③ 이번 달 변동비

**정의:** 매출에 따라 변동되는 비용

**예시:**

- 외주비 (프로젝트별)
- 재료비 (제품별)
- 광고비 (캠페인별)
- 매출 수수료 (플랫폼·결제 수수료)

**점검:**

- 매출의 30~50% 권장
- 변동비 비율 높아지면 → 마진 압박

---

### ④ 이번 달 이익

**정의:** 매출 - (고정비 + 변동비) = 영업이익

**점검:**

- 양수(+): 흑자 ✅
- 음수(-): 적자 ⚠️
- 3개월 연속 적자 → 🔴 비상

**해석:**

- 이익 ≠ 통장 잔고 ⚠️ (5번 항목 참조)
- 이익이 나도 외상매출 미회수면 현금 부족 가능

---

### ⑤ 통장 잔고 + 다음 달 예상 입출금

**정의:**

- **현재 통장 잔고** (실제 가용 현금)
- 다음 달 입금 예정 (외상매출 회수 + 신규 매출)
- 다음 달 지출 예정 (고정비 + 변동비 + 세금)

**계산:**

- 다음 달 말 예상 잔고 = 현재 잔고 + 입금 예정 - 지출 예정

**경보:**

- 다음 달 말 예상 잔고 < 0 → 🔴 위기 (현금 위기)
- 잔고가 매월 감소 추세 → 🟡 주의 (6개월 후 마이너스 가능)
- 잔고 = 월 고정비 3배 이상 권장 (안전망)

---

## 매출 ≠ 이익 ≠ 현금 차이 ⚠️

### 사례: 매출 1억, 이익 5천, 현금 -200

```
| 구분 | 금액 | 차이 원인 |
|---|---|---|
| 매출 (손익계산서) | 1억 | - |
| 이익 (손익계산서) | 5천 | - 5천 (경비) |
| 통장 잔고 (현금) | -200 | - 5천 (외상매출 미회수) - 200 (재고) |
```

**왜 다른가?**

| 매출 vs 이익 | 매출에서 경비 차감 |
| 이익 vs 현금 | 이익이 났어도:

- 외상매출 미회수 → 통장에 안 들어옴
- 재고 증가 → 자금 묶임
- 선급금 지급 → 자금 사용
- 부채 상환 → 자금 사용 |

**흑자도산:**

> "흑자도산은 거짓말이 아닙니다. 이익은 났는데 현금이 없어서 망하는 사장님 진짜 있습니다."

## 5숫자 대시보드 표 형식

```markdown
| #   | 지표              | 금액    | 전월 대비 | 비고      |
| --- | ----------------- | ------- | --------- | --------- |
| 1   | 이번 달 매출      | 1,470만 | +15%      | A사 신규  |
| 2   | 고정비            | 320만   | -         | -         |
| 3   | 변동비            | 480만   | -10%      | 외주 줄임 |
| 4   | 이번 달 이익      | 670만   | +50%      | -         |
| 5a  | 통장 잔고 (현재)  | 850만   | -200만    | -         |
| 5b  | 다음 달 예상 잔고 | 650만   | -200만    | 🟡 주의   |
```

## 위기 경보 자동 판단

```
🟢 양호:
- 매출 전월 대비 +/- 10% 이내
- 고정비 < 매출의 50%
- 이익 > 0
- 잔고 > 월 고정비 3배

🟡 주의:
- 매출 전월 대비 -10~30%
- 고정비 매출의 50~70%
- 이익 > 0이지만 감소 추세
- 잔고 > 월 고정비 1배

🔴 위기:
- 매출 전월 대비 -30%+ (또는 3개월 연속 감소)
- 고정비 매출의 70%+
- 이익 < 0
- 다음 달 말 예상 잔고 < 0
- 잔고 < 월 고정비 1배
```

## 매월 30분 점검 루틴

1. **(5분)** 카드·통장 명세 확인 → 매출·고정비·변동비 합산
2. **(5분)** 5숫자 표에 입력
3. **(5분)** 다음 달 예상 입출금 추정
4. **(10분)** 위기 경보 점검 + 액션 3가지
5. **(5분)** PDF로 출력 또는 옵시디언/노션에 저장

## 위기 시 즉시 액션

### 🟡 주의 단계

1. 외상매출 회수 (거래처 정중한 카톡)
2. 고정비 줄일 항목 검토 (구독 정리)
3. 정책자금 매칭 시작 (`매칭` 모드)

### 🔴 위기 단계

1. **즉시 신용 점수 확인** (NICE/KCB) — 850+ 유지가 안전
2. 정책자금 또는 대출 신청 (`자가진단` + `사업계획`)
3. 세무사·재무 컨설턴트 긴급 상담
4. 비상 자금 확보 (가족·지인·신용카드 한도 활용)
