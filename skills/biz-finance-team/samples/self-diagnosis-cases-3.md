# 정책자금 5체크 자가진단 — 케이스 3건 학습용 샘플

> biz-finance-team 자가진단 모드의 학습용 샘플.
> 자주 만나는 3가지 케이스: 체납 / 매출 부족 / 신규 사업자.

---

## 케이스 #1 — 체납 있는 사장 (가장 흔함)

### 입력

```yaml
체납여부:
  국세: 없음
  지방세: 없음
  4대보험: 있음 (건강보험 50만원, 6개월 미납)
사업자등록일: 2023-03-15 (3년차)
업종: 1인 디자인 (한국표준산업분류 - 디자인업)
연매출_3년: [8000만, 7500만, 6000만]
신청_희망액: 1,500만 (운전자금)
사용목적: 광고비 + 외주비
상환계획: 월 28만원 × 60개월
```

### 출력

```markdown
# 정책자금 5체크 자가진단 — {{회사명}}

> 🏦 재무 AI 준비 자료입니다.

## 🚦 종합 신호등: 🔴 보완 필수

**총점: 64/140 (46%) — 자동 탈락 사유 있음**

## 5체크 진단표

| #   | 항목                      | 상태                    | 점수  | 영향          |
| --- | ------------------------- | ----------------------- | ----- | ------------- |
| 1   | 체납 — 국세               | ✅ 없음                 | 20/20 | -             |
| 1   | 체납 — 지방세             | ✅ 없음                 | 20/20 | -             |
| 1   | 체납 — 4대보험 (건강보험) | 🔴 있음 (50만원, 6개월) | 0/20  | **자동 탈락** |
| 2   | 사업자 상태               | ✅ 정상 (3년)           | 20/20 | -             |
| 3   | 매출 자료                 | ✅ 3년 보유             | 20/20 | -             |
| 4   | 사용 목적                 | 🟡 광고+외주 (모호)     | 12/20 | 구체화 필요   |
| 5   | 상환 가능성               | 🟡 월매출 약 4%         | 18/20 | 안전          |

## 🔴 즉시 조치 (탈락 방지)

### 1. 건강보험 50만원 즉시 납부

- **국민건강보험공단 1577-1000** 전화 또는 앱
- 분할납부 신청 가능 (10회 분할)
- 납부 즉시 **완납증명서** 발급 가능

### 2. 완납증명서 신청 후 정책자금 신청

- 완납증명서가 첨부되어야 자격 회복

## 🟡 보완 권고

### 사용 목적 구체화

현재: "광고비 + 외주비" (모호)
→ 구체화 예시:

- 네이버 키워드 광고 800만 (3개월 분)
- 외주 디자이너 500만 (2명 × 2.5만/시간 × 100시간)
- 운영비 200만 (서버·SaaS 6개월 분)

## 🎯 보완 후 예상 신호등

체납 해결 + 사용 목적 구체화 완료 시:

- **새 총점: 124/140 (89%) → 🟢 양호**
- 신청 가능성 높음

---

📚 근거 법령

- 중소기업기본법 제2조 (소상공인 정의)
- 소상공인기본법 제2조

🛡️ 체납 해결 후 공식 사이트(소상공인마당) + 담당관 확인 필수.
```

## 케이스 #2 — 매출 부족 신규 사업자

### 입력

```yaml
체납여부:
  모두: 없음
사업자등록일: 2025-09-01 (8개월차)
업종: 온라인쇼핑몰
연매출_3년: [없음, 없음, 작년 4개월만 1, 500만]
신청_희망액: 1,000만 (시설자금 — 사진 촬영 장비)
사용목적: 사진 촬영 장비 + 스튜디오 임대료
상환계획: 월 19만 × 60개월
```

### 출력

```markdown
# 정책자금 5체크 자가진단

## 🚦 종합 신호등: 🟡 주의

**총점: 90/140 (64%) — 일반 자금 제한, 창업자금 가능**

## 5체크 진단표

| #   | 항목           | 상태             | 점수  | 영향                 |
| --- | -------------- | ---------------- | ----- | -------------------- |
| 1   | 체납 — 국세    | ✅ 없음          | 20/20 | -                    |
| 1   | 체납 — 지방세  | ✅ 없음          | 20/20 | -                    |
| 1   | 체납 — 4대보험 | ✅ 없음          | 20/20 | -                    |
| 2   | 사업자 상태    | 🟡 정상 (8개월)  | 10/20 | 일반 자금 1년 미충족 |
| 3   | 매출 자료      | 🟡 1년 미만      | 8/20  | 창업자금만 가능      |
| 4   | 사용 목적      | ✅ 시설자금 명확 | 20/20 | -                    |
| 5   | 상환 가능성    | 🟡 월매출 약 5%  | 17/20 | 안전 (매출 가정 시)  |

## 🎯 권장 — 일반 자금 X, 창업자금 O

신규 사업자(1년 미만)는 일반 정책자금 자격 부족.
대신 **창업자금** 신청 권장:

### 창업자금 5사이트

- K-Startup: https://k-startup.go.kr (특히 청년창업·여성창업)
- 소상공인마당: https://sbiz.or.kr (소상공인 창업자금)
- 중진공: https://kosmes.or.kr (창업기반자금)

## 🟡 보완 권고

### 1. 사업계획서 5대 — 신규 사업자 강조 ⭐

- 신규 사업자는 매출 자료가 부족하므로 **사업계획서 가중치 ↑**
- `/biz-finance-team 사업계획` 호출 권장

### 2. 신용 점수 850+ 유지

- 매출 부족분을 신용 점수로 보완

### 3. 창업 특화 보증 활용

- 지역신보 창업특례 보증 (보증서 받으면 대출 가능)

---

🛡️ 일반 정책자금 vs 창업자금 — 공식 사이트에서 자격 직접 확인.
```

## 케이스 #3 — 양호한 사장 (이상적 케이스)

### 입력

```yaml
체납여부:
  모두: 없음
사업자등록일: 2020-04-01 (5년차)
업종: 컨설팅
연매출_3년: [12000만, 9500만, 8000만]
신청_희망액: 3,000만 (R&D 자금 — AI 기반 컨설팅 도구 개발)
사용목적: 외주 개발자 인건비 + 서버 운영비 + AI API 비용
상환계획: 월 56만 × 60개월
```

### 출력

```markdown
# 정책자금 5체크 자가진단

## 🚦 종합 신호등: 🟢 양호

**총점: 132/140 (94%) — 신청 가능, 통과 가능성 높음**

## 5체크 진단표

| #   | 항목           | 상태               | 점수  | 영향           |
| --- | -------------- | ------------------ | ----- | -------------- |
| 1   | 체납 — 국세    | ✅ 없음            | 20/20 | -              |
| 1   | 체납 — 지방세  | ✅ 없음            | 20/20 | -              |
| 1   | 체납 — 4대보험 | ✅ 없음            | 20/20 | -              |
| 2   | 사업자 상태    | ✅ 정상 (5년)      | 20/20 | -              |
| 3   | 매출 자료      | ✅ 3년 + 성장 추세 | 20/20 | 매출 우상향 ⭐ |
| 4   | 사용 목적      | ✅ R&D 명확        | 20/20 | 기술 개발 ⭐   |
| 5   | 상환 가능성    | 🟡 월매출 약 5.6%  | 12/20 | 안전           |

## 🎯 추천 정책자금

### 1순위: 중진공 R&D 자금

- https://kosmes.or.kr → 사업안내 → 정책자금
- R&D 자금은 통과율 높음 (혁신 평가)

### 2순위: K-Startup 기술 사업화 자금

- https://k-startup.go.kr
- AI·기술 분야 가중치

### 3순위: 신용보증기금 R&D 보증

- 신청 가능 자금 보증 → 대출

## 🟢 추가 권고

### 1. 사업계획서 5대 — 강조점

- **시장 규모 + 성장률** (AI 컨설팅 도구 시장)
- **기술 차별성** (특허 또는 핵심 알고리즘)
- **매출 성장 근거** (3년 우상향 + 향후 가속)

### 2. 분기 1회 사업 진척 보고

- R&D 자금은 보통 분기 보고 의무
- 정량 지표 (개발 단계 / 매출 성과) 사전 정의

---

🛡️ 신청 가능성 매우 높음. 다만 분기 보고·정량 평가 의무 사전 확인.
```

## 케이스별 학습 패턴

### 🔴 체납 케이스 → 즉시 해결 + 완납증명서

### 🟡 매출 부족 → 일반 X, 창업자금 O

### 🟢 양호 → 사업계획서 강조점 살리기

각 케이스별로 보완 우선순위가 완전히 다름. AI는 사장님 케이스를 정확히 진단 후 해당 액션 권고.
