# /biz-ai-secretary — 1인사업자 통합 AI 비서 🎯

3개 팀장(법무·세무·재무)을 한 번에 호출 + 통합 진단 + 7일 실행계획 1장.

> "사장님 사업 5줄만 넣으면 법무 5개 / 세무 5개 / 재무 5개 / 전문가 질문 15개 / 이번 주 할 일 3개가 한 번에."

---

## ⚠️ 필수 면책 고지

> 🎯 **통합 AI 비서 준비 자료입니다.** 모든 결정·실행·서명·신고는 전문가 검토 후 본인이.

---

## 사용 시점

### ✅ 호출해야 하는 경우

- **한 장으로 사업 전반 진단** 받고 싶을 때 (월 1회 권장)
- 어떤 팀장을 호출해야 할지 모를 때 (자연어 질문 라우팅)
- **7일 실행계획 카드** 만들 때
- **사업 프로필 + 작업 이력** 확인할 때
- 키워드: `사업가AI비서`, `통합 진단`, `한 번에`, `마스터 프롬프트`, `7일 실행`, `이번 주 할 일`, `월간 점검`

### ⚠️ 호출하지 말아야 하는 경우

- 특정 영역 깊은 분석이 필요한 경우 → 해당 팀장 직접 호출
- 빠른 단일 질문 → `/biz-legal-team` / `/biz-tax-team` / `/biz-finance-team` 직접

## 4개 모드

| #   | 모드        | 트리거          | 동작                           |
| --- | ----------- | --------------- | ------------------------------ |
| 1   | **통합** ⭐ | `통합`          | 3팀장 병렬 호출 → 마스터 1장   |
| 2   | 라우팅      | `[자연어 질문]` | 자연어 → 적절한 팀장 자동 분기 |
| 3   | 7일계획     | `7일계획`       | 단 1개 작업 카드               |
| 4   | 상태        | `상태`          | 프로필 + 작업 이력 + 추천      |

> 인자 없이 `/biz-ai-secretary`만 호출하면 4개 모드 메뉴 표시.

---

## 모드별 처리 흐름

### 1. 통합 모드 ⭐

**입력 (5줄):**

```yaml
업종: (한 줄)
매출: (월 또는 연)
가장큰고민: (한 줄, 자유서술)
이번주_결정사항: (한 줄, 선택)
이번주_예정상담: 변호사/세무사/은행원/없음
```

**처리:**

1. 사업 프로필 자동 로드 (없으면 `/biz-profile` 자동 호출 안내)
2. 3개 팀장 스킬 **병렬 호출**:
   - `/biz-legal-team 점검` (가장 시급한 계약 또는 일반)
   - `/biz-tax-team 분류` (이번 달 지출)
   - `/biz-finance-team 자가진단` (정책자금 신호등)
3. 결과를 통합 마스터 포맷으로 합성 (`templates/unified-master-1page.md`)
4. 전문가 질문 15개 통합 (법무5 + 세무5 + 재무5)
5. 이번 주 할 일 3개 추출 (각 팀장 우선순위 1개씩)

**출력:** 통합 마스터 1장 (한 장으로 사업 전반)

---

### 2. 라우팅 모드

**자연어 → 팀장 자동 분기**

**예시:**

```
/biz-ai-secretary 외주 계약서에 위약금 30%, 너무 과해?
→ 자동 분기: /biz-legal-team 독소

/biz-ai-secretary 골프장 비용 28만원 경비?
→ 자동 분기: /biz-tax-team 분류

/biz-ai-secretary 운전자금 1000만 가능?
→ 자동 분기: /biz-finance-team 자가진단
```

**키워드 사전:** `templates/routing-keywords-dict.md` 참조

**분기 신뢰도 < 70% 시:**

- 사용자에게 확인 질문
- "이건 [법무 / 세무 / 재무] 영역으로 보입니다. 맞나요?"

---

### 3. 7일계획 모드

**처리:**

1. 통합 모드 결과의 "이번 주 할 일 3가지" 활용 (있으면)
2. **사장이 1개만 선택**하도록 강제
   - 원고 핵심: "이것도 하고 저것도 하고 → 결국 하나도 안 함"
3. `templates/7-day-execution-card.md` 5항목 카드 생성

**5항목:**

- 언제? (날짜·시간 명시)
- 필요 자료
- 완료 기준 (구체적)
- 알릴 사람 (단톡·짝·가족)
- 완료 보상

---

### 4. 상태 모드

**출력:**

- 사업 프로필 (10항목)
- 최근 작업 이력 (최근 7일)
- 다음 추천 액션
- 누적 산출물 (계약서 점검 N건 / 세무사 패키지 N건 / 정책자금 진단 N건)
