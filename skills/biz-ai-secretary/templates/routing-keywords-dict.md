## 🤖 분기 결정 로직

```
사용자 자연어 질문
    │
    ├─ 명확한 키워드 매칭 (신뢰도 90%+)
    │   → 해당 팀장 모드 자동 호출
    │
    ├─ 부분 매칭 (신뢰도 70~89%)
    │   → 팀장 추천 + "맞나요?" 확인
    │
    ├─ 모호 (신뢰도 < 70%)
    │   → "이건 [법무 / 세무 / 재무] 영역으로 보입니다. 어느 쪽일까요?"
    │
    └─ 통합 키워드
        → /biz-ai-secretary 통합 모드
```

---

## 분기 신뢰도 향상 팁

### 사장님 입력에서 자동 추출하는 단서

1. **명사 키워드** (계약서·영수증·정책자금 등)
2. **숫자 + 단위** ("100만원" → 금액 / "1억" → 매출)
3. **시점** ("이번 달" → 월간 점검 / "5월" → 종소세)
4. **상대방** ("거래처" → 법무 / "세무사" → 세무 / "은행" → 재무)

### 모호 케이스 예시

```
"이번 달 매출이 별로야" → 5숫자 모드 (재무) 또는 분류 모드 (세무)?
→ 확인: "매출 추이를 보고 싶으세요? (재무) 영수증 분류가 필요하세요? (세무)"

"이거 처리해도 돼?" → 너무 모호
→ 확인: "구체적으로 어떤 영역인가요? (계약서 / 영수증 / 정책자금)"
```
