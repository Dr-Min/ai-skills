| #   | 영역                      | 누가                 | 메모 |
| --- | ------------------------- | -------------------- | ---- |
| 1   | 계약서 최종 서명          | 변호사 검토 후 본인  | -    |
| 2   | 손해배상액 산정           | 변호사               | -    |
| 3   | 세금 신고서 작성·전송     | 세무사               | -    |
| 4   | 경비 인정 최종 판단       | 세무사               | -    |
| 5   | 원천세·부가세 마감일 관리 | 세무사 + 본인        | -    |
| 6   | 정책자금 자격 단정        | 공식 사이트 + 담당관 | -    |

## 사용 시점

### `/biz-ai-secretary 통합` 호출 시 자동 작성

1. 사업 5줄 입력 받음
2. 3개 팀장 병렬 호출
3. 결과를 위 포맷으로 합성
4. 이번 주 할 일 3가지 자동 추출 (각 팀장 우선순위 1개씩)
