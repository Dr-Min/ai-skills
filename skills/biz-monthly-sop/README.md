## 🧩 5단계

| #    | 주기           | 시간    |
| ---- | -------------- | ------- |
| 🟢 1 | 결제 직후      | 30초    |
| 🟢 2 | 매주 (월)      | 10분    |
| 🟡 3 | 매월 (월말) ⭐ | 30분    |
| 🟡 4 | 분기           | 1시간   |
| 🔴 5 | 신고 전        | 2~3시간 |

## 💡 핵심 1줄

**"🟢 결제 직후 메모 → 매주 정리 → 매월 30분 패키지 → 분기 점검 → 신고철 세무사"**

## 📚 종속

- /biz-tax-team (분류·패키지 활용)
- /biz-finance-team (매월 5숫자)

🛡️ AI는 매뉴얼까지. 신고·서명은 세무사 + 본인.

## 해결하는 문제

증빙 정리를 신고 직전에 몰아서 하면 누락과 판단 지연이 커집니다. 이 스킬은 결제 직후부터 신고 전까지 일을 작은 반복 단위로 분해해, 월말에는 이미 세무사에게 넘길 수 있는 형태가 되도록 만듭니다.

## 입력과 결과물

- 입력: 업종, 과세유형, 결제수단, 현재 증빙 보관 방식과 신고 일정
- 결과: 행동·필요자료·AI 명령·산출물·전문가 확인의 5열 SOP
- 다듬기: 실행하기 어려운 단계를 5분 단위로 분해
- 인쇄: 책상 위에 둘 수 있는 A4 한 장 요약

## 설치

```bash
python install.py --no-law-mcp --skills biz-monthly-sop,biz-tax-team
```
