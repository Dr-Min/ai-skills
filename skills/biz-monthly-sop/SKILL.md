# /biz-monthly-sop — 매월 30분 세무 매뉴얼 📅

신고 직전 폭발 안 하고, 매월 30분으로 분산해 끝내는 5단계 SOP.

> SOP = Standard Operating Procedure (반복 가능한 작업 절차서) = 매뉴얼

---

## ⚠️ 면책 고지

> 📅 본 SOP는 사장님의 매월 작업 매뉴얼입니다. 신고는 세무사·전문가 영역.

## 모드별 처리 흐름

### 1. 생성 모드

**입력:**

- 사업 프로필 자동 로드 (`/biz-profile`)
- (선택) biz-tax-team 분류 결과 자동 참조

**처리 — 5단계 SOP 자동 생성:**

원고 4교시 5-3절 명령 그대로:

> "지금까지의 자료를 종합해 우리회사의 월간 세무·증빙 SOP를 만들어 주세요. 5단계로 — 결제 직후 / 매주 / 매월 / 분기 / 신고 전. 각 단계에 행동 + 자료 + AI 명령 + 결과물 + 전문가 확인 여부 표시."

**5단계 표** (`templates/5-stage-sop-table.md` 참조):

| 단계 | 주기              | 시간          |
| ---- | ----------------- | ------------- |
| 🟢 1 | 결제 직후         | 30초 (실시간) |
| 🟢 2 | 매주 (월요일)     | 10분          |
| 🟡 3 | 매월 (월말) ⭐    | 30분          |
| 🟡 4 | 분기 (3개월 1회)  | 1시간         |
| 🔴 5 | 신고 전 (5월·1월) | 2~3시간       |

**5컬럼:**

- 행동 / 자료 / AI 명령(프롬프트) / 결과물 / 전문가 확인 여부

---

### 2. 다듬기 모드

**처리:**

1. 모드 1 출력의 각 행 검토
2. 5분 이상 걸릴 작업 자동 분해
3. AI 명령(프롬프트)이 비어있는 행은 "수동" 표시
4. 전문가 확인 누락된 행 자동 표시

**추가 컬럼:**

- 소요시간: 30초 / 5분 / 10분 / 30분 / 1시간 / 2시간
- 분해 권고: 5분 초과 시 "○○ 단계로 분해 권장"
- 자동화 가능성: 🤖 자동 / 🤝 보조 / 👤 수동

---

### 3. 인쇄 모드

**처리:**

1. 표를 인쇄 최적화 (가로 A4)
2. 색상 흑백 호환 (이모지로 구분)
3. 상단: 회사명 + 작성일
4. 하단: 안전 푸터
5. md → PDF 변환 명령 안내

**변환 명령 안내:**

```bash
pandoc ~/.lbiz-aibu/sop-2026-05.md -o ~/.lbiz-aibu/sop-2026-05.pdf \
  --pdf-engine=weasyprint --css=A4-landscape.css
```

또는 마크다운 뷰어(Marked·Typora·Bear)로 출력.
