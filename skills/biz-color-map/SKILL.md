# /biz-color-map — 업무 자동화 결정 지도 🚦

새 업무가 들어오면 → 어떤 색인지 먼저 확인 → 그다음 행동.

---

## ⚠️ 면책 고지

> 🚦 본 3색맵은 사장님 업무 자동화 범위 결정 가이드입니다. 빨강은 절대 AI 단독 금지.

---

## 사용 시점

### ✅ 호출해야 하는 경우

- 사업 시작 1~3개월차 — **AI 자동화 범위를 정해야 할 때**
- 새 업무 카테고리 발생 시 (어떤 색인지 모름)
- 4교시 워크북 실습 4 자동 생성
- **사무실 벽 / 책상 위 붙일 1쪽** 필요시
- 키워드: `사업가3색맵`, `업무 분류`, `3색`, `자동 vs 전문가`, `벽지`, `습관`

### ⚠️ 호출하지 말아야 하는 경우

- 깊은 분석이 필요한 단일 업무 → 해당 팀장 직접 호출
- 직원 KPI 평가 — 본 스킬 범위 외

## 모드별 처리 흐름

### 1. 생성 모드 — 20개 업무 자동 분류

**입력:**

- 사업 프로필 자동 로드
- (선택) 사장님 업종 + 거래 특성

**처리:**

1. 업종 특성 + 거래 빈도 + 1인사업자 일반 패턴으로 20개 업무 후보 생성
2. 각 업무를 3색 기준으로 분류
3. **🔴 5개 이상 강제** (안전 가드, 원고 검증 기준)
4. 사장님 케이스 적용 컬럼 (일반론 X)

**분류 기준** (`checklists/7-red-zones.md` 참조):

#### 🟢 초록 — 자동 처리 OK

- 자료 요약·정리
- 영수증 분류·체크리스트
- 일정 관리
- 단순 문구 작성 (블로그 초안 등)
- 검색 결과 요약

#### 🟡 노랑 — AI 초안 + 사장 확인

- 거래처 메일 작성
- 견적서·제안서 초안
- SNS 콘텐츠
- 미팅 의제·회의록 정리
- 사업계획서 일부 (5대 중 시장·매출모델)
- 영수증 사업관련성 모호한 건

#### 🔴 빨강 — 무조건 전문가

- 계약 서명 / 손해배상 산정 / 분쟁 대응
- 세금 신고서 작성·전송 / 가산세 결정 / 경비 인정 최종 판단
- 대출 실행 / 정책자금 자격 단정
- 개인정보 보호 의사결정
- 인사·노무 분쟁

→ `templates/20-tasks-classification.md` 형식으로 출력
