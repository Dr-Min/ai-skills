- [ ] 20개 이상 항목인가?
- [ ] 빨강이 5개 이상인가?
- [ ] 사장님 업종 맥락이 반영됐나?
- [ ] 각 행에 "사장님 케이스 적용" 컬럼이 채워졌나?
