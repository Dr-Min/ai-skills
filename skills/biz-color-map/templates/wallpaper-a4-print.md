
- macOS: Marked 2 → PDF
- Typora → PDF Export
- 옵시디언 → Export to PDF

### 옵션 3: 캡처

## 🖼️ 디자인 가이드

### A4 (포트레이트)

- 상단 30%: 제목 + 회사명
- 중단 60%: 3색 분류 (🟢🟡🔴 균등 배분)
- 하단 10%: 빨강 가드 푸터

### 색상 (컬러 인쇄 시)

- 🟢: 연두색 배경
- 🟡: 연노랑 배경
- 🔴: 연분홍 배경
- 글자: 검정

### 흑백 인쇄 시

- 이모지(🟢🟡🔴)로 구분
- 굵기 차별화 (빨강은 더 굵게)

## 📍 추천 위치

### 사무실

1. **모니터 위·옆** — 컴퓨터 작업 중 자주 봄
2. **책상 옆 벽** — 옆자리 동료도 같이 봄
3. **화이트보드** — 수정·추가 가능

### 집 (재택근무)

1. **컴퓨터 데스크 위 벽**
2. **냉장고** — 일어날 때마다 봄
3. **현관문 안쪽** — 출퇴근 시 봄

### 명함 크기 (휴대용)

1. **지갑** — 외근·미팅 중 참조
2. **다이어리 첫 장** — 매일 펼침
3. **노트북 안쪽** — 가방 열 때마다 봄
