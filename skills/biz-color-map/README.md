## 💡 핵심 1줄

**"새 업무 = 먼저 색깔 확인 = 그다음 행동"**

🛡️ 빨강은 절대 AI 단독 금지.

## 해결하는 문제

AI가 할 수 있는 일과 맡겨도 되는 일은 다릅니다. 이 스킬은 자동화 가능성만 보지 않고 서명, 신고, 책임, 자격, 대출처럼 결과를 되돌리기 어려운 업무를 전문가 영역으로 분리합니다.

## 입력과 결과물

- 입력: 업종, 사업 규모, 현재 업무 목록 또는 새로 생긴 업무
- 결과: 분류 이유, AI가 할 수 있는 범위, 사람이 확인할 지점, 다음 행동
- 인쇄 모드: 사무실에 붙일 수 있는 A4 한 장 업무 지도

## 설치

```bash
python install.py --no-law-mcp --skills biz-color-map
```

## 한계

색상은 업무의 책임 경계를 정하는 운영 도구이지 법률적 적법성이나 세무 처리의 최종 판정이 아닙니다. 같은 업무도 금액, 계약 상대, 업종 규제와 회사 권한에 따라 색이 바뀔 수 있습니다.
