# 7가지 빨강 영역 — 절대 AI에게 맡기면 안 되는 7가지

> 출처: 3교시 강의 원고 Slide 65.
> 모든 사업가-\* 스킬의 공통 안전 가드.

## 7가지 카탈로그

### 1. 계약서 최종 서명 🔴

**왜 빨강:**

- 법적 효력 발생 시점
- AI 잘못된 판단 시 평생 법적 책임
- 약관규제법 적용 여부 등 복잡한 법리

**누가:**

- 변호사 검토 후 본인 서명
- AI는 점검·독소 검출까지만 (`/biz-legal-team 점검` / `독소`)

---

### 2. 손해배상액 산정 🔴

**왜 빨강:**

- 통상손해 vs 특별손해 구분 (민법 제393조)
- 위약금 vs 손해배상 효과 차이 (민법 제398조)
- 입증 책임·증거 평가 필요

**누가:**

- 변호사 산정
- AI는 협상 톤·근거 자료까지만

---

### 3. 세금 신고서 작성·전송 🔴

**왜 빨강:**

- 잘못 신고 시 가산세
- 신고 정정·경정청구 등 사후 절차 복잡
- 세무사 자격 영역 (세무사법)

**누가:**

- 세무사 작성·전송
- AI는 자료 정리·세무사 패키지까지만 (`/biz-tax-team 패키지`)

---

### 4. 경비 인정 최종 판단 🔴

**왜 빨강:**

- 사업관련성 + 증빙 + 금액 적정성 종합 판단
- 세무 조사 시 부인 가능성
- 업종별·금액별 관행 차이

**누가:**

- 세무사 확인
- AI는 🟢🟡🔴 1차 분류 + 메모 권고까지만

---

### 5. 원천세·부가세 마감일 관리 🔴

**왜 빨강:**

- 마감일 놓치면 가산세 (본세의 3% + 일별 0.025%)
- 분기·반기·연 단위 일정 복잡
- 자동화 안 된 영역 (사장님 직접 챙겨야)

**누가:**

- 본인 + 세무사 일정 관리
- AI는 마감일 안내·계산까지만 (`/biz-tax-team 원천세` / `부가세`)

---

### 6. 정책자금 자격 단정 🔴

**왜 빨강:**

- 사업별 자격 요건 상이 + 자주 변경
- 모집 일정·금리·조건 실시간 변동
- 잘못된 정보로 신청 시 시간·비용 낭비

**누가:**

- 공식 사이트 + 담당관 확인
- AI는 5체크 자가진단·후보 매칭까지만 (`/biz-finance-team 자가진단` / `매칭`)

> ⚠️ "현재 모집 중" 단정 절대 금지.

---

### 7. 대출 실행 🔴

**왜 빨강:**

- 신용 점수 영향
- 상환 부담 평생
- 한도·금리·조건 협상 필요

**누가:**

- 은행 심사 통과 후 본인 결정
- AI는 5체크·사업계획서·은행원 상담 패키지까지만

## 빨강 영역 자동 검출

3색맵 생성 시 다음 키워드는 자동으로 🔴로 분류:

- "최종" / "확정" / "신고" / "납부" / "서명" / "양도" / "위임"
- "대출" / "자격" / "결정" / "판단" / "산정"

---

## 💡 빨강을 줄이려고 하지 말 것

사장님이 자주 묻는 것:

> "이거 자동으로 안 되나요?"

→ 답: **빨강은 자동화 X. AI 효율 추구하다 큰 사고 가능.**
**빨강 영역 = 인간(전문가)이 가치 발휘하는 곳.**

---

## 빨강 vs 노랑 vs 초록 — 결정 기준

```
"잘못되면 어떻게 되나?"

→ "법적 책임" / "가산세" / "신용 영향" → 🔴 빨강 (무조건 전문가)
→ "관계·이미지 손상" / "기회 비용" → 🟡 노랑 (AI 초안 + 사장 확인)
→ "단순 시간 손실" → 🟢 초록 (자동 OK)
```
