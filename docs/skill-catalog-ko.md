# 스킬 상세 카탈로그

이 문서는 `ai-skills`에 포함된 스킬을 사람이 빠르게 고를 수 있도록 정리한 안내서입니다. 설치 가능한 이름과 경로는 `catalog.json`을 기준으로 하며, 정확한 실행 절차와 가드레일은 각 스킬의 `SKILL.md`가 최종 기준입니다.

## 빠른 선택

| 하고 싶은 일 | 먼저 볼 스킬 | 함께 쓰기 좋은 스킬 |
|---|---|---|
| 사업 전반을 한 번에 점검 | `biz-ai-secretary` | `biz-profile`, 법무·세무·재무 팀 스킬 |
| 계약·세무·자금 중 한 분야만 깊게 점검 | `biz-legal-team`, `biz-tax-team`, `biz-finance-team` | `law-mcp-setup` |
| 거래처나 사업자의 공개 사실을 교차 확인 | `biz-health-check` | 공공데이터 6종 스킬 |
| 한 주제를 대화형으로 제대로 배우기 | `adaptive-mastery-tutor` | 없음 |
| AI 영상 한 쇼트를 끝까지 제작 | `cinema-studio-pipeline` | `min-edit-seedance-2-0` |
| 음악의 실제 공격음에 맞춰 컷 편집 | `sync-cuts-to-music` | 없음 |
| 이야기와 동선을 초 단위 쇼트로 설계 | `timed-storyboard` | 영상 생성 스킬 |
| 새 Codex 스킬 만들기 | `skill-builder-101` | 없음 |

## Business

### [`biz-ai-secretary`](../skills/biz-ai-secretary/README.md)

- 한 줄 정의: 법무·세무·재무 팀 스킬을 한 번에 호출하고 우선순위를 합치는 1인사업자용 디스패처입니다.
- 사용 시점: “사업 전체를 점검해줘”, “이번 주 무엇부터 해야 해?”처럼 분야를 가르기 전 통합 진단이 필요할 때 사용합니다.
- 핵심 기능: 세 팀 결과를 법무 5개, 세무 5개, 재무 5개, 전문가 질문, 7일 실행 카드로 통합합니다.
- 입력과 결과: 자연어 사업 고민 또는 저장된 사업 프로필을 받아 한 장짜리 마스터 결과와 이번 주 핵심 작업을 만듭니다.
- 의존성과 주의: `biz-legal-team`, `biz-tax-team`, `biz-finance-team`이 필요합니다. 전문가 판단이 필요한 항목은 자동 확정하지 않습니다.

### [`biz-color-map`](../skills/biz-color-map/README.md)

- 한 줄 정의: 사업 업무를 자동 처리 가능, 사장 확인 필요, 전문가 전용의 세 단계로 분류합니다.
- 사용 시점: 어떤 일을 AI에 맡겨도 되는지, 검토가 필요한지, 바로 전문가에게 가야 하는지 경계를 정할 때 사용합니다.
- 핵심 기능: 기본 20개 업무와 새 업무를 3색으로 분류하고, 위험 업무가 과도하게 자동화되지 않도록 안전 가드를 둡니다.
- 입력과 결과: 업종과 업무 목록을 받아 화면용 표 또는 A4 한 장짜리 업무 지도를 만듭니다.
- 의존성과 주의: 분류는 의사결정 보조이며 법률·세무 책임 판단을 대체하지 않습니다.

### [`biz-finance-team`](../skills/biz-finance-team/README.md)

- 한 줄 정의: 정책자금, 사업계획, 현금흐름, 은행 상담 준비를 구조화하는 소상공인 재무팀 스킬입니다.
- 사용 시점: 정책자금 신청 가능성을 점검하거나 사업계획서와 은행 상담 자료를 준비할 때 사용합니다.
- 핵심 기능: 정책자금 5체크, 사업계획 핵심 답변, 매월 5개 숫자 대시보드, 자금 후보 매칭, 상담 패키지를 제공합니다.
- 입력과 결과: 사업 상태, 매출·비용·잔고, 자금 목적을 받아 자가진단과 제출 초안, 질문 목록을 만듭니다.
- 의존성과 주의: 공고 조건과 금융기관 심사는 수시로 바뀌므로 신청 전 공식 공고와 담당기관 확인이 필요합니다.

### [`biz-health-check`](../skills/biz-health-check/README.md)

- 한 줄 정의: 사업자등록번호와 상호를 바탕으로 여러 공공 출처의 사실을 한 리포트에 병렬 정리합니다.
- 사용 시점: 거래 전 사업자 상태, 가입 사업장, 공개 체납·제재, 법인 개요, 인허가 상태를 교차 확인할 때 사용합니다.
- 핵심 기능: 하위 공공데이터 스킬을 묶어 출처, 조회시점, 일치 여부, 확인 불가 항목을 분리합니다.
- 입력과 결과: 사업자등록번호, 법인명·상호, 필요 시 지역을 받아 근거 링크가 있는 실사 리포트를 만듭니다.
- 의존성과 주의: 위험점수나 신용등급을 만들지 않으며, 동명이인과 공개명단의 한계를 명시합니다.

### [`biz-legal-team`](../skills/biz-legal-team/README.md)

- 한 줄 정의: 계약서 작성·검토와 변호사 상담 준비를 돕는 1인사업자 법무팀 스킬입니다.
- 사용 시점: 필수 조항, 독소조항, 미수금 회수 장치, 갑을 불균형을 점검하거나 계약서 초안을 만들 때 사용합니다.
- 핵심 기능: 7대 필수 조항, 빠진 조항, 미수금 장치, 독소조항 기준으로 검토하고 수정 제안 문장과 상담 질문을 만듭니다.
- 입력과 결과: 계약서 파일 또는 거래 조건을 받아 이슈표, 수정 문안, 상담 메모를 제공합니다.
- 의존성과 주의: 최신 법령 인용에는 `law-mcp-setup`이 필요하며, 결과는 변호사 검토를 대체하지 않습니다.

### [`biz-monthly-sop`](../skills/biz-monthly-sop/README.md)

- 한 줄 정의: 세무와 증빙 관리를 반복 가능한 월간 표준 작업 절차로 바꿉니다.
- 사용 시점: 결제 직후부터 신고 전까지 무엇을 언제 정리할지 월간 루틴이 필요할 때 사용합니다.
- 핵심 기능: 결제 직후, 매주, 매월, 분기, 신고 전의 5단계로 작업과 자료, AI 명령, 결과물, 전문가 확인을 연결합니다.
- 입력과 결과: 업종, 결제수단, 신고 형태, 현재 관리 습관을 받아 5분 단위 SOP와 A4 요약을 만듭니다.
- 의존성과 주의: `biz-tax-team` 결과를 재사용할 수 있으며 실제 신고 일정은 관할 세무 기준으로 확인해야 합니다.

### [`biz-profile`](../skills/biz-profile/README.md)

- 한 줄 정의: 다른 사업 스킬이 공통으로 사용할 사업 정보를 인터뷰로 정리합니다.
- 사용 시점: 사업 스킬을 처음 쓰거나 매번 회사 정보를 다시 설명하지 않도록 기본 프로필을 만들 때 사용합니다.
- 핵심 기능: 기본 10문항과 법무·세무·재무 사각지대 질문을 통해 공통 컨텍스트를 수집합니다.
- 입력과 결과: 대표자, 업종, 매출 구조, 인력, 계약·세무·자금 현황을 받아 로컬 프로필 JSON과 요약을 만듭니다.
- 의존성과 주의: 프로필에는 민감한 사업정보가 들어갈 수 있으므로 공개 저장소가 아닌 사용자 로컬에만 저장합니다.

### [`biz-tax-team`](../skills/biz-tax-team/README.md)

- 한 줄 정의: 영수증과 지출 분류부터 세무사 전달 패키지와 세금 시뮬레이션까지 돕습니다.
- 사용 시점: 경비 인정 가능성, 부가세·원천세·종합소득세 준비, 절세 제도 점검이 필요할 때 사용합니다.
- 핵심 기능: 증빙 3색 분류, 7폴더 전달 구조, 세무사 질문, 노란우산·IRP·기부 진단, 주요 세금 계산 모드를 제공합니다.
- 입력과 결과: 거래내역, 영수증, 과세유형, 소득·비용 자료를 받아 분류표, 계산 초안, 세무사 전달 요약을 만듭니다.
- 의존성과 주의: 최신 법령 확인에는 `law-mcp-setup`을 사용하며 최종 신고와 공제 판단은 세무사 또는 공식 안내를 확인합니다.

## Legal

### [`law-mcp-setup`](../skills/law-mcp-setup/README.md)

- 한 줄 정의: Codex에서 Korean Law MCP를 안전하게 설치·연결·복구·검증합니다.
- 사용 시점: 법제처 인증값을 등록하거나 MCP가 보이지 않거나 연결이 실패할 때 사용합니다.
- 핵심 기능: 인증값 형식과 API 연결을 확인하고 로컬 자격증명 파일과 Codex MCP 설정을 구성합니다.
- 입력과 결과: 사용자가 로컬에서 제공하는 법제처 Open API `OC` 값을 받아 연결된 MCP 설정과 검증 결과를 만듭니다.
- 의존성과 주의: Node.js 20.19 이상과 `korean-law-mcp`가 필요합니다. 인증값을 채팅·로그·Git에 출력하거나 저장하지 않습니다.

### [`adaptive-mastery-tutor`](../skills/adaptive-mastery-tutor/README.md)

- 한 줄 정의: 설명, 학습자 답변, 진단, 복습을 반복해 실제 숙달까지 이끄는 대화형 튜터입니다.
